# SNR

通常环境的信噪比：

1. 办公室：~20 dB
2. 餐厅：~7 dB
3. 地铁：~5 dB

信噪比=10\*log(声音能量/噪音能量)

当信噪比为负值时，说明噪音大于声音能量，反之，声音能量较高，信噪比越高，声音越好

## 场景-1

较安静环境（信噪比 10 dB，声音能量是噪音的 10 倍）

该环境中，人声能够清楚听到

## 场景-2

基础噪音环境（信噪比 5 dB，声音能量是噪音的 3 倍）

该环境中，噪音相对大，可以听到人声

## 场景-3

高噪环境 （信噪比 0 dB，噪音能量和声音能量相当）

该环境中，噪音还是非常嘈杂，但能够清楚听到人声

## 场景-4

高噪环境 （信噪比 -5 dB，噪音能量是声音能量 3 倍）

该环境中，噪音非常嘈杂，但还能够听到人声

## 场景-5

高噪环境（信噪比-10 dB，噪音能量是声音的 10 倍）

该环境中，噪音非常大，基本淹没人声
